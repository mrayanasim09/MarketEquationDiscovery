# Security Policy

## Supported Versions

As this is a research repository, active security updates are generally only provided for the latest stable release associated with the manuscript.

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | :white_check_mark: |
| 2.0.x   | :x:                |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please do not disclose it publicly on the issue tracker.

Instead, please send an email to **mrayanasim09@gmail.com**.

We will endeavor to respond to your report within 72 hours. If the vulnerability is accepted, we will coordinate a timeline for a patch and subsequent public disclosure.

## Scope

This project involves data processing and machine learning modeling for academic purposes. While we take standard precautions, the code is intended to be run in secure, isolated environments by researchers. Vulnerabilities requiring physical access to the machine or compromised research environments are generally considered out of scope.
